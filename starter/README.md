## Project Overview

This project predicts whether an individual's income exceeds $50,000 using the UCI Census Income dataset.

### Features

- Data Cleaning
- Machine Learning Model Training
- FastAPI REST API
- Unit Testing
- CI/CD with GitHub Actions
- Render Deployment
